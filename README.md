# LedgerLine

**Every rupee accounted for. Every movement traceable.**

LedgerLine is a secure money movement application built around a provable ledger. It supports account management, deposits, withdrawals, transfers, and transaction statements with a focus on financial integrity and security.

## Project Status

Under development.

## Planned Technology Stack

- Frontend: React.js
- Backend: Node.js and Express.js
- Database: PostgreSQL
- Authentication: JWT and bcrypt
- Testing: Jest and Supertest
- Containerization: Docker

## Core Requirements

- Role-based authentication: Administrator, Account Holder, and Auditor.
- Account creation and balance viewing.
- Deposits, withdrawals, and transfers.
- Money conservation and prevention of negative balances.
- Idempotent financial requests.
- Concurrency-safe money operations.
- Account statements and audit records.

## Project Structure

- `frontend/` – User interface
- `backend/` – API and business logic
- `database/` – Database schema and setup
- `docs/` – Documentation
- `tests/` – Automated tests
